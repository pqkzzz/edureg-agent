# EduReg Agent

Vietnamese University Regulation RAG Assistant.

## Day 1-2 Progress

- FastAPI backend
- Streamlit frontend
- PostgreSQL
- Qdrant
- Docker Compose

## Run

```bash
cp .env.example .env
docker compose up --build
```

## Services

- Backend: http://localhost:8000
- Swagger: http://localhost:8000/docs
- Frontend: http://localhost:8501
- Qdrant dashboard: http://localhost:6333/dashboard
